### About me

I'm a developer based in Chile who likes owning a product from the first sketch to the thing people actually use.

On the web, that means storefronts with real checkout and payments, built on Next.js. On the Mac, it means native SwiftUI apps that feel like they belong on the system. In Rust, it means small, careful tools for the cloud services I use every day: read-only by default, and strict about cost.

I care about the details that decide whether someone keeps using what I built: fast pages, clear flows, sensible defaults, and tests that catch problems before users do.
